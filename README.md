# Атлант Сервис Обмен — сайт

Статический сайт: три страницы, без базы данных и бэкенда.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Главная |
| `obmen-rub-uah.html` | Услуга «Обмен RUB ⇄ UAH» |
| `perestanovka-nalichnyh.html` | Услуга «Перестановка наличных» |
| `404.html` | Страница «не найдено» |
| `styles.css` | Все стили |
| `img/` | Логотип, глобус, иллюстрации, иконки, превью для мессенджеров |
| `.htaccess` | Настройки Apache — нужны только на обычном хостинге |

Служебное: `build.js` собирает папку `dist` для деплоя, `pages.py` пересобирает страницы услуг из шапки и подвала главной, `deploy.py` подставляет домен и делает `robots.txt` с `sitemap.xml`.

## Настройки в Timeweb App Platform

- Тип приложения: **фронтенд**, фреймворк — **Другое**
- Команда сборки: `npm run build`
- Директория с результатом: `dist`

После привязки репозитория каждый `git push` пересобирает сайт автоматически.

## Как поменять текст

Тексты лежат прямо в HTML. Описание услуг — блок между комментариями
`<!-- ===== НАЧАЛО КОНТЕНТА ===== -->` и `<!-- ===== КОНЕЦ КОНТЕНТА ===== -->`
на страницах услуг.

Если правите шапку, подвал или блок контактов — правьте их в `index.html`
и выполните `python pages.py`, чтобы изменения разошлись по остальным страницам.
